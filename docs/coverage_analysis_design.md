# 覆盖仿真设计文档（Coverage Analysis Design）

> 文档状态：首发实现依据（P0 必备）
> 适用范围：地面区域覆盖仿真（H3 网格 + 仰角规则 + C/dBm 功率规则）
> 关联模块：`backend/app/coverage.py`、`backend/app/h3grid.py`、`backend/app/orbital.py`、`frontend` 覆盖结果可视化

---

## 1. 目标与口径

- **目标**：给定星座（千帆 / 国网 / 合成星座）与仿真时间区间，量化地面区域在每一时间步的覆盖情况，并按两种规则给出"是否被覆盖"及质量指标。
- **坐标与时间**：内部统一 **UTC**；地面坐标用 WGS84 经纬高。仿真输入时间先转 UTC 再计算。
- **单位**：角度 `degree`，距离 `km`，频率 `Hz`，功率 `dBm`/`dBW`，时间 `s`。
- **最小可比单元**：H3 网格单元（cell）。每个 cell 用其**中心点**（lat, lon）近似该单元的地面位置进行链路计算（cell 尺度 ≪ 卫星高度，近似误差可忽略）。

---

## 2. 地面区域定义与 H3 网格化

### 2.1 区域定义
- 区域以**多边形**（GeoJSON Polygon，外环经纬度列表）描述，可多边形裁剪。
- 默认区域：中国陆地主体包围盒近似多边形（lat 18°–54°，lon 73°–135°），可在 `config` / 高级设置中修改。
- 默认分辨率：`res = 4`（H3 第 4 级）。

### 2.2 H3 网格分辨率选择

| 分辨率 | 单个 cell 面积(约) | 边长(约) | 适用 |
|---|---|---|---|
| 3 | ~1.2×10⁴ km² | ~ 35 km | 大区域快速概览 |
| **4** | ~1.8×10³ km² | ~ 15 km | **默认**，区域级覆盖 |
| 5 | ~2.6×10² km² | ~ 6 km | 城市级精细 |
| 6 | ~3.6×10¹ km² | ~ 2.5 km | 终端级（慎用） |

- 选用 **Uber H3**（`h3` Python 库）生成 `polyfill`，返回 cell id 列表。
- 每个 cell 预计算：中心 `(lat, lon, alt=0)`、ECEF 单位向量 `g_hat`、ECEF 位置 `g = g_hat * R_e`。
- 输出 `coverage_samples` 时记录 `h3_index` 与中心经纬度。

> 性能提示：cell 数量 = 区域面积 / 单 cell 面积。中国主体 @res4 ≈ 数千 cell；结合卫星数与时间步需做向量化（见 §6）。

---

## 3. 卫星位置传播（前置）

链路计算依赖卫星 **ECEF** 位置与地心距。采用 **二体 + J2 一阶长期项** 开普勒模型（`orbital.py`）：

1. 由轨道根数（epoch, a, e, i, Ω, ω, M₀）在目标时间 t 求解开普勒方程得真近点角 ν。
2. 近焦点坐标 → 经 Ω, i, ω 旋转得 **ECI** 位置 `r_eci`。
3. 地球自转角 `θ(t) = θ_GMST(epoch) + ω_e·(t−epoch)`，将 ECI 旋至 **ECEF**：`r_ecef = Rz(−θ)·r_eci`。
4. 输出：`(x,y,z)_ecef (km)`、`lat, lon, alt`、`地心距 r`。

常量：`μ=398600.4418 km³/s²`，`R_e=6378.137 km`，`ω_e=7.2921159e-5 rad/s`，`J2=1.08262668e-3`。

## 4. 简单规则：仰角约束（Elevation Constraint）

对地面 cell 与卫星，视线向量 `ρ = s − g`（均为 ECEF），其中 `s` 为卫星 ECEF，`g` 为地面点 ECEF。

- 地心单位向量 `ĝ = g / |g|`。
- 仰角：`el = arcsin( (ρ · ĝ) / |ρ| )`，范围 `[-90°, 90°]`。
- 覆盖判定（简单规则）：cell 在时刻 t 被覆盖 ⇔ 存在卫星满足 `el ≥ el_min`。
- **默认 `el_min = 10°`**（推荐 5°–25°）。低仰角受地形/多径影响大，10° 为稳健默认。

> 仅用几何关系，不依赖载荷/频率参数，适合快速覆盖评估与链路预算前的"可达性"初筛。

---

## 5. 复杂规则：接收功率 C/dBm 约束（Link Budget）

在仰角可达基础上，增加功率可行性判定。

### 5.1 链路预算物理量（发射端 → 接收端）

| 符号 | 含义 | 默认/推荐 |
|---|---|---|
| `P_t` | 卫星发射功率 | 20 W (43 dBm / 13 dBW) |
| `G_t` | 发射天线增益 | 12 dBi |
| `EIRP` | 等效全向辐射功率 | `P_t[dBW] + G_t` ≈ 25 dBW |
| `f` | 载波频率 | 19.7 GHz（Ku/Ka 段） |
| `B` | 噪声带宽 | 30 MHz |
| `G_r` | 终端接收天线增益 | 3 dBi（0.3m 抛物面） |
| `L_fs` | 自由空间损耗 | `20·log10(4π d f / c)` |
| `L_atm` | 大气/雨衰损耗 | 2 dB（默认，可调） |
| `L_pol` | 极化损耗 | 0.5 dB |
| `L_point` | 指向/失配损耗 | 0.5 dB |
| `T_s` | 系统噪声温度 | 300 K（含天线+接收机） |
| `k` | 玻尔兹曼常数 | 1.380649e-23 J/K |
| `G/T` | 品质因数 | `G_r[dB] − 10·log10(T_s)` |

### 5.2 计算公式

1. **自由空间损耗**
   `L_fs(dB) = 20·log10(4π·d·f / c)`，其中 `c = 299792458 m/s`，`d` 为斜距（m）。
2. **接收载波功率（dBW）**
   `C = EIRP − L_fs − L_atm − L_pol − L_point`（dBW）
3. **换算 dBm**
   `C_dBm = C + 30`
4. **噪声功率（dBm）**
   `N = 10·log10(k·T_s·B) + 30`
5. **载噪比**
   `C/N0 = EIRP − L_fs − L_atm − L_pol − L_point + G/T − 10·log10(k)`（dBHz）
   `C/N = C/N0 − 10·log10(B)`
6. **覆盖判定（复杂规则）**：
   - 先满足仰角 `el ≥ el_min`；
   - 且 `C_dBm ≥ C_min`（默认接收灵敏度 **−85 dBm**，可调）。

> 复杂规则综合"几何可达 + 功率可解调"，更贴近真实链路可用性。默认参数适用于 Ka 段窄波束终端；用户可在"星座高级设置/载荷管理"中调整。

## 6. 计算与输出流程

### 6.1 输入
- 星座 ID（及筛选后的 NORAD ID 子集，默认仅稳定壳层）
- 仿真时间区间（today 24h / 时间轴所选日 24h / 自定义 起−止+时长）
- 采样间隔（默认 **15 s**）
- 规则类型（simple_elevation / complex_power）
- 区域与 H3 分辨率（默认中国包围盒 / res4）
- 规则参数（el_min、C_min、EIRP、f、B、G_r、T_s、L_atm…）

### 6.2 分阶段计算（记录耗时）

1. **卫星传播（propagation）**：对所有卫星在全部时间步向量化求 ECEF。
2. **仰角约束（elevation）**：对每个 (t, cell) 求最大仰角及对应卫星。
3. **功率约束（power）**：（仅复杂规则）对可达卫星算 C/dBm，取最大。
4. **结果聚合（aggregation）**：生成 per-cell-per-step 覆盖结论、覆盖卫星、max el、max C/dBm。

向量化策略：固定时间步 t，将卫星 ECEF（S×3）与 cell 地面 ECEF（C×3）广播为 (S×C×3)，一次性算全部 `ρ` 与仰角；再沿卫星轴取 max。外层仅遍历时间步。NumPy 全程向量化，避免 Python 循环。

### 6.3 输出字段（`coverage_samples` 行）

| 字段 | 说明 |
|---|---|
| `task_id` | 仿真任务 ID |
| `time_step` | 时间步索引 |
| `timestamp_utc` | UTC 时间 |
| `h3_index` | H3 单元 ID |
| `lat`, `lon` | cell 中心 |
| `covered_simple` | 简单规则是否覆盖 |
| `covered_complex` | 复杂规则是否覆盖 |
| `covering_norad_ids` | 覆盖卫星 NORAD ID 列表（JSON） |
| `max_elevation_deg` | 最大仰角 |
| `max_c_dBm` | 最大接收功率 dBm |
| `distance_km` | 对应斜距 |

### 6.4 汇总指标
- 每时间步被覆盖 cell 比例（区域覆盖率曲线，ECharts 时序图）。
- 每 cell 在仿真时长内累计被覆盖时长 / 时间步数（cell 级覆盖热力，Cesium H3 着色）。
- 平均/最差覆盖率、覆盖中断次数。

## 7. 可视化方式（前端）

1. **Cesium H3 着色**：将 `coverage_samples` 按 (cell, 当前时间步) 抽稀为单元格多边形，按 `covered` / `max_el` / `max_c_dBm` 着色；细连线从 cell 连到覆盖卫星（稀疏抽样避免卡顿）。
2. **时间滑块联动**：覆盖着色随时间轴播放刷新。
3. **点击 cell**：弹出该 cell 在各时间步的覆盖详情（覆盖卫星、仰角、C/dBm 曲线，ECharts）。
4. **覆盖率时序图**：ECharts 折线，显示简单/复杂规则覆盖率随时间变化。
5. **性能优化**：cell 多边形边界预计算缓存；Web Worker 计算轨道；覆盖结果分页/按时间步流式加载；H3 多边形用 `Primitive`/`GroundPrimitive` 批量渲染。

---

## 8. 性能优化方案

- **向量化**：全部 (S×C) 广播在 NumPy 内完成，外层仅遍历时间步。
- **索引**：`coverage_samples` 建立 `(task_id, time_step)` 与 `h3_index` 复合索引；`historical_ephemeris` 以 `(norad_id, epoch)` 唯一索引去重。
- **降采样**：采样间隔、H3 分辨率、卫星子集均可调；默认参数保证 P0 演示在分钟级内完成。
- **内存控制**：逐时间步释放中间数组，避免 (S×C×T) 三维数组常驻。
- **可复现**：任务记录随机种子与全部输入参数，`seed` 固定时结果可复现（合成星座参数确定性生成）。

## 9. 默认参数速查（可直接用于实现）

```
el_min = 10.0            # 度
C_min = -100.0           # dBm，接收灵敏度（复杂规则门槛）
P_t_dBW = 20.0           # 100W
G_t_dBi = 27.0           # 发射增益（相控阵）
EIRP_dBW = P_t_dBW + G_t_dBi = 47.0
freq_Hz = 12.0e9         # Ku 段
B_Hz = 30e6
G_r_dBi = 3.0
T_s_K = 300.0
L_atm_dB = 2.0
L_pol_dB = 0.5
L_point_dB = 0.5
region = 中国包围盒 (lat 18..54, lon 73..135)
h3_res = 4
sample_interval_s = 15
default_duration_h = 24
```
> 说明：上述默认参数下，复杂规则比简单规则更严格——仅当仰角较高、斜距较短（卫星接近星下点）时 C/dBm 才超过门槛，因此复杂覆盖率低于简单覆盖率，可直观对比两种规则。提高 `C_min`（如 -90 dBm）会进一步收紧；降低则趋于简单规则。
